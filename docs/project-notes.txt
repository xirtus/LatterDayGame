PLAY THE GAME — FIRST LOCAL BUILD
================================
Open http://127.0.0.1:8923/game/ while the project server is running.
The illustrated report remains at / and the material study at /character-study/.

First setup from this folder:
  npm install
  npx playwright install chromium
  npm run dev

If port 8923 is already serving this folder, reuse that server instead:
  npm run build
Then refresh /game/. Do not start a second server on the same port.

Controls: WASD/arrows walk, Shift run, drag to look, E interact (hold to pray),
Space continue dialogue, 1 first person, 3 third person, V free camera,
Q/R down/up in free camera, J journey journal, Escape pause.
Touch controls appear on narrow screens. Free camera does not move Joseph.

This playable has 32 core chapters, 8 clearly speculative era chapters,
2 documentary insertions, 28 optional records and 286 objectives, staged Three/Eight Witnesses,
regional procedural environment
families with era-specific scenery, local Meshy characters, saves, subtitles,
procedural ambience, and optional actual-recording playback. Bubble portals link
the speculative eras. This is an explorable chapter-and-dialogue prototype,
not the finished, fully choreographed historical experience described below.
Many characters still use marked provisional models, and spoken takes are pending.

Models: add exports to meshy/, then run npm run build and reload the game.
Use child/teenage/young-adult and character names in filenames. Sources remain
unchanged. game/ASSETS.txt explains matching, optimization, and missing models.
game/content/model-checklist.csv lists every active identity, missing exports,
rig status, selected file, and chapter appearances, ordered by production need.
The Characters tab lists all roles in the current chapter, including later beats.
The interface uses a scripture-book cover, golden-plate emblem, vellum pages,
contents, chapter marginalia, and historical notes rather than a generic RPG HUD.
Jesus has white-robed and red-coat model variants, with one CHRIST identity and
voice. The white rig is used for the Grove/temple/celestial commission; red for
the imagined reunion and speculative era mission. Both local rigs are integrated.
Recordings: game/audio/README.txt and game/audio/recording-plan.csv give the
358-line MOSSlanding packet, including 126 new record lines. Drop approved takes into game/audio/takes/ using
their line IDs, run npm run build, then refresh. No voices are generated by build.

Validation, with the server running:
  npm test
  node tools/test_game.mjs --all
  node tools/test_actors.mjs
  node tools/test_actors.mjs --browser
  python3 tools/test_game_story.py
  node tools/test_record_play.mjs
  node tools/test_record_game.mjs
Screenshots and results are written to game/evidence/.

===============================
Open index.html in a browser or Codex to read the illustrated report.
The report works from local files and does not require a running game server.

Contents
32 chapter treatments covering Joseph's life and an explicitly imaginative
postmortal and celestial continuation; 40 concept panels across five boards;
69 casting and voice-family briefs; working scene dialogue and audition lines;
Celandia reuse and style direction; MOSSlanding workflow; source references;
and the optional xChurch-inspired seven-era Zion campaign.
