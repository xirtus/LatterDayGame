PLAY THE GAME — FIRST LOCAL BUILD
================================
Open http://127.0.0.1:8923/game/ while the project server is running.
The illustrated report remains at / and the material study at /character-study/.

First setup from this folder:
  npm install
  npx playwright install chromium
  npm run dev

If port 8923 is already serving this folder, reuse that server instead:
  npm run build
Then refresh /game/. Do not start a second server on the same port.

Controls: WASD/arrows walk, Shift run, drag to look, E interact (hold to pray),
Space continue dialogue, 1 first person, 3 third person, V free camera,
Q/R down/up in free camera, J journey journal, Escape pause.
Touch controls appear on narrow screens. Free camera does not move Joseph.

This first playable has 32 core chapters, 8 clearly speculative era chapters,
146 walk-to interactions, staged Three/Eight Witnesses, 14 procedural environment
families with era-specific scenery, local Meshy characters, saves, subtitles,
procedural ambience, and optional actual-recording playback. Bubble portals link
the speculative eras. This is an explorable chapter-and-dialogue prototype,
not the finished, fully choreographed historical experience described below.
Many characters still use marked provisional models, and spoken takes are pending.

Models: add exports to meshy/, then run npm run build and reload the game.
Use child/teenage/young-adult and character names in filenames. Sources remain
unchanged. game/ASSETS.txt explains matching, optimization, and missing models.
Recordings: game/audio/README.txt and game/audio/recording-plan.csv give the
189-line MOSSlanding packet. Drop approved takes into game/audio/takes/ using
their line IDs, run npm run build, then refresh. No voices are generated by build.

Validation, with the server running:
  npm test
  node tools/test_game.mjs --all
  node tools/test_actors.mjs
  node tools/test_actors.mjs --browser
Screenshots and results are written to game/evidence/.

ILLUSTRATED PREPRODUCTION REPORT
===============================
Open index.html in a browser or Codex to read the illustrated report.
The report works from local files and does not require a running game server.

Contents
32 chapter treatments covering Joseph's life and an explicitly imaginative
postmortal and celestial continuation; 40 concept panels across five boards;
65 casting and voice-family briefs; working scene dialogue and audition lines;
Celandia reuse and style direction; MOSSlanding workflow; source references;
and the optional xChurch-inspired seven-era Zion campaign.
The character-design addition includes four new character concept sheets,
the complete modeling roster, and a live original/toon material comparison.

Important working files
docs/campaign.json             Chapter dates, history, play, art, and sources
docs/cast.json                 Character voice descriptions and auditions
docs/dialogue.json             Working dialogue beats
docs/sermon-passages.json      Adapted King Follett doctrinal passages
docs/voice-cast.csv            Export for casting and voice preparation
docs/recording-manifest.csv    Export for scene recording and selected takes
docs/sources.json              Source titles, links, and uses
docs/art-prompts.json          Full initial/revision prompts and selected art
docs/character-art-prompts.json  Character sheet prompts and saved user references
docs/modeling-plan.json        Modeling priorities and full cast grouping
docs/modeling-roster.csv       Every voice profile with current model status
docs/meshy-audit.json          Read-only GLB geometry, texture, rig, and clip audit
docs/design.html              Design, theology, engineering, and production prose
docs/template.html            Report presentation and small navigation controls
art/                          Selected project-local concept boards
meshy/                        User-provided source models, preserved unchanged
character-study/index.html    Live original/toon comparison; requires HTTP server
docs/evidence/                Desktop and mobile report captures

Rebuild the report and CSV exports from this directory
python3 tools/build_report.py

Refresh the local model inventory before rebuilding after new Meshy exports
python3 tools/audit_meshy.py

Rebuild the optional 3D comparison with the existing Celandia dependencies
node tools/build_character_study.mjs

The report ZIP excludes the large meshy source folder. The material study uses
that local folder; source models must be present when running it elsewhere.

The report is a preproduction and first-pass script packet, not a finished
game or a recording-locked screenplay. A separate playable prototype is now
available under game/ as described above. Voices have not been generated or
trained. Concept images are reference proposals, not final game models or
documentary reconstructions. Celandia and MOSSlanding have not been modified.
